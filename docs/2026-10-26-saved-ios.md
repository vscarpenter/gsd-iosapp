# Saved on iOS: implementation and verification

Branch: `feat/saved-tasks`, based on `06dca9b`.
Scope: the approved web Saved behavior, native short notes and reviewed return to
matrix. App version remains 3.5.0 (36); distribution is a separate step.

## What changed and why

Move an incomplete task to Saved from its existing actions menu. Find Saved in
iPhone Browse or the iPad/Mac Library sidebar. Notes and links stay visible beside
the title; tap to edit up to 600 UTF-16 units. Return reviews the quadrant and
optional date before restoring the same task to active work. Saved has local
title/note/tag search; global palette results identify and route Saved items.

An additive v7 migration and existing PocketBase `saved_at` field preserve placement
through storage, trash, archive and backup. TaskStore reads current rows for Saved
actions and rejects completion or new timers until return. Save offers Undo; delete
Undo restores from the current trash record. Active filters, counts, analytics,
widgets, badges, reminders, Spotlight suggestions and App Intent suggestions omit
Saved. The full task graph still protects dependencies and account/import data.

No new service, dependency, production migration or production data mutation is
needed. Sync stays optional and offline use works without an account. Existing
record-level last-write-wins behavior applies to competing edits; this feature
does not add character-level note merging.

## Reproduce

Run `swift test` in `GSDKit`. For the real backend check, use Bun from the web
checkout and supply the native script, web checkout and PocketBase binary:

```sh
bun /path/to/gsd-iosapp/scripts/verify-saved-sync.mjs /path/to/web /path/to/pocketbase
```

Use PocketBase 0.40.4, matching web system tests. The Darwin arm64 archive SHA-256
is `eeb619ea4f8a06421daedb946d133bed269fea334a760941d147f76befc25ebc`.
The script binds only localhost and creates its own temporary data and auth.

Regenerate the project with `xcodegen generate`, then use the `GSDScreenshots`
scheme with `-only-testing:GSDScreenshotTests/SavedFlowTests`,
`TEST_RUNNER_SAVED=1` and `-collect-test-diagnostics never`. Every UI launch uses
the existing isolated demo harness; no installed account/store is seeded.

For local manual testing, open this checkout's `GSD.xcodeproj`, choose the GSD
scheme and an iPhone or iPad simulator, and run. On a task choose **Move to Saved**,
open **Browse → Saved** (iPhone) or **Library → Saved** (iPad), edit notes, and use
**Return to matrix** to review its quadrant/date. Sync remains the existing opt-in
account flow; the integration tests use disposable credentials on localhost.
